ORBITAL — mission music library

ORBI plays exactly five songs, chosen by the crew. Copy the MP3 files here with exactly these names
(or load them in ORBITAL → Profile & Data → Music library):

  Bruno Mars - Count on Me (Official Lyric Video).mp3     → sad or lonely
  @coldplay - A Sky Full Of Stars (Lyrics).mp3             → stressed
  The Script - Hall Of Fame (Lyrics).mp3                   → needs motivation
  Katy Perry - Firework (Lyrics).mp3                       → wants to feel happy
  Billy Joel - Piano Man (Lyrics).mp3                      → wants to relax

Nothing else is ever played. If a file is missing, ORBI says so.
Do not upload these files to a public website (e.g. a public GitHub repository): they are copyrighted.
Use "Load MP3" in Profile & Data on each computer instead.
